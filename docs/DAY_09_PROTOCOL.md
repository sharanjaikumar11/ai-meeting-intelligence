# Day 9 evaluation protocol

Frozen before predictions on 2026-11-21. Required metrics: WER, action precision/recall/F1, decision precision/recall/F1, and QA correctness.

Three purposively selected AMI English Mix-Headset excerpts total 560 seconds. ES2004a 885–1049, ES2004d 1420–1660, IS1003b 1458–1614. These excerpts have no prior saved model predictions in this project. ES2004a was reserved in Day 1. This is a small project-held-out pilot, not the official AMI test split or an independent speaker/team split; model pretraining overlap is unknown. Selection used human transcripts to cover assignments, a changed design, unresolved proposals, and unanswerable questions. No positive explicit task deadline or accepted deadline change occurs here; those cannot receive an accuracy score from this sample.

Reference text comes from AMI manual v1.6.2. Structured labels in evaluation/day09_gold.json were authored by the coding assistant against those human transcripts before inference, not by independent human annotators. Report this limitation prominently. Original full-meeting abstractive summaries are not used as excerpt gold. No tuning of application code or labels after predictions; record errors for Day 10 instead.

## Frozen inference

Application Day 8 code, Whisper small, English, CPU, four threads, seed zero, temperature zero, no conditioning on previous text, word timestamps; pyannote community-1 with automatic speaker count and 300-second context. Gemini 2.5 Flash: one action extraction, draft/review decision extraction, and two questions batched into draft/review QA per case. Schema repairs use existing bounded application behavior. Maximum 20 attempted SDK calls across this run, SDK retries disabled, starts spaced at least 16 seconds. Preserve raw cached responses, attempts, exact source/code/gold hashes and all predictions. No summaries required for these metrics. Local cap does not measure other clients' project usage.

## Scoring rules

WER = (substitutions + deletions + insertions) / reference words. Use JiWER and Whisper EnglishTextNormalizer identically on both texts. Reference lexical words selected by midpoint in [start,end), ordered by onset; overlap is serialized, so simultaneous speech affects WER. Score the full ASR transcript returned for the exact interval. Pool counts across cases; also report each case.

Actions are specific future work assignments, commitments or concrete suggestions. Vague individual work, passive notifications, meeting logistics, and unassigned product choices are excluded. Match predicted task intent one-to-one against gold, requiring no contradictory essential scope. Wording may differ. Extra/duplicate tasks are false positives, omitted tasks false negatives. Owner/deadline differences do not change task-intent matching; assess them separately on matched items and disclose recall coverage. A correct role is sufficient when only a role is stated; speaker attribution requires evidence, not arbitrary letter-to-ID mapping. Never count a proposed session start as a deadline. All-null deadline data supports only a missing-deadline check, not positive deadline accuracy.

Decision P/R/F1 measures final agreed substantive product/design outcomes, including explicitly reaffirmed requirements. Only output topics whose final state is agreed and kind is decision enter the prediction set. Proposals, historical mentions without reaffirmation, unresolved topics, cost arithmetic, and task assignments do not count as final product decisions. One topic maps to at most one gold outcome; a composite outcome must preserve all essential parts and avoid contradiction. Duplicates are false positives. Additional qualitative review covers change tracking and unresolved issues, without inventing a statistically meaningful change metric from one case.

Extraction precision = TP/(TP+FP), recall = TP/(TP+FN), F1 = 2TP/(2TP+FP+FN). Report undefined denominators as null, not 100%. Primary aggregate is micro counts, not mean case percentages.

QA: all six frozen questions scored against human-reference expectations. Full = all essential requested facts correct, no unsupported substantive claim, and citations support retained claims (or correct abstention for absent information). Partial = some essential facts missing but no contradictory answer; incorrect = wrong/unsupported central claim or unjustified abstention on answerable question. Strict correctness = full / all questions; also report partial and incorrect counts without treating partial as full. Separate answerable questions from missing-information questions. Same-model review is inference, not the evaluator. Manual semantic adjudication is recorded in a hashed prediction-to-gold ledger with reasons; this is assistant review, not independent human validation.

Schema/source evidence validation is a separate integrity check, never an accuracy metric. Failed extraction yields zero predictions and preserves all gold false negatives. Failed QA counts incorrect. Failed ASR must be reported as failure, not silently excluded. No model-generated text may replace gold. Any changed code/labels after the freeze must invalidate the held-out label or be documented as a separate new run.
